# Bozza visiva — I nostri lavori

Studio estetico del 29 ottobre 2026. Aprire `/references/mockups/works/index.html` sul server Vite locale. Non è una rotta del sito e non modifica la homepage.

Riutilizza navbar, footer, font, palette e fotografie aziendali esistenti. Le tredici fotografie scelte servono a valutare la composizione, senza correzioni o ricostruzioni. Le etichette delle categorie e «Tutti i lavori» illustrano la futura navigazione; la raccolta completa non è implementata. Zanzariere è una categoria proposta dall’utente: nessuna foto è stata attribuita a questa categoria senza verifica.

Direzione proposta: homepage con due o tre immagini per categoria, pagina dedicata con raccolta completa filtrabile e apertura delle fotografie. I gruppi relativi allo stesso intervento andranno confermati sulle foto originali, senza inventare progetti o dati dei clienti. Eventuali correzioni di luce per la home saranno copie separate dagli originali.
